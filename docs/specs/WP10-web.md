# WP10 · 用户前端

规格来源:`docs/ui-ux-spec.md` §3;公开层、控制台壳与逐屏交互定稿见 WP13-autodl-redesign.md。

## 目标
用户控制台整站:市场/创建/实例/详情/费用/存储 六屏 + 公开主页、登录、概览、设置。

## 屏清单(路由与关键行为)
1. 算力市场 `/market`:筛选链 + SKU 表格单选 + 底部结算条;CTA 即库存(「N 卡可租」/「已租完」);未登录可浏览,下单跳登录;页脚合规条
2. 创建实例 `/market/create/:skuId`:规格/镜像级联/数据盘(可行内直建)/SSH 密钥(可行内添加)/名称 + 结算条(开机费用 vs 日常费用);经济档知情同意 modal
3. 容器实例 `/instances`(登录后默认落地页):策略提示条 + 表格(状态徽标含冻结倒计时/利用率 sparkline/今日消费/SSH 复制/Jupyter 直达);关机与释放多级确认
4. 实例详情 `/instances/:uuid`:监控(ECharts,断源降级文案)/ 连接 / 事件时间线(明示「此记录即计费依据」)/ 账单 四 Tab;危险区释放
5. 费用中心 `/billing`:余额卡 + 充值 modal(二维码轮询)+ 消费概览(成本归因环图)+ 账单/收支明细/导出 CSV
6. 存储 `/storage`:挂载全景图 + 数据盘列表(扩容抽屉/到期倒计时/多级删除防护)+ 空态引导

另:公开主页 `/`、登录 `/login`、概览 `/dashboard`、设置 `/settings`(SSH 公钥/通知阈值)。

## 技术约束
布局壳(顶栏压侧栏、可折叠侧栏)见 WP13;数据走生成 hooks、文案/状态映射走 packages/ui、antd 6 原生组件——见 CLAUDE.md 硬性规范。
