# SuperDL 文案风格规范(voice & tone)

所有用户可见文案(两端 locales JSON、后端 `core/messages.py`)遵守本规范;禁词由 `scripts/check-copy-banned.sh` 在 CI 强制。
基调:克制、具体、可执行,措辞原创。把用户当同行,不当新手;讲事实与后果,不讲情绪与卖点。

## 句式规则

1. **标题 = 名词短语**(「容器实例」「费用中心」),不带解释性括号或副标题;术语定义放 tooltip。
2. **按钮 = 动宾**,≤6 字(「创建并开机」「生成注册命令」);危险动作带宾语(「释放实例」而非「确认」)。
3. **空态 = 一句话 + 一个动作**(「还没有实例」+「去算力市场」);不用「快去…吧」式口吻。
4. **禁用 tooltip 必须给前置条件**(「关机后才能释放实例」),不解释显而易见的操作。
5. **错误 = 事实 + 下一步**(「数据盘挂载中,请先释放对应实例」);后端 message_key 是约束类文案的单一事实源,前端不复写。
6. **确认框 = 后果前置**(「确认强制停止?将立即结算尾账并通知用户」)。
7. **金额/时长/日期一律走 format 函数**,文案里不出现裸「¥」「元」拼接(经 `common.gbMonthPrice` 等模板键)。

## 禁则

- **实现细节不出口**:轮询间隔、巡检周期、outbox/poller/handler 等机制词、仓库路径、组件版本号,一律不进 UI。
- **内部术语不出口**:「走调账」「端口池」等运营/资源模型词,对用户改为可执行表述。
- **不做空头承诺**:未实现的功能不写进文案;预留功能统一「即将上线」。
- **不堆排比模具**:「A · B · C」三段式口号限 hero 一处;卖点写成事实句。
- 感叹号、emoji、「您」(用零称呼或「你」语境化)、时间承诺(「一分钟开出」)不使用。
- 禁词表(CI 强制,见脚本):智能、强大、轻松、一键*、全方位、高效、极速、助力、赋能、颠覆、极致(*「一键加入」等既有产品名词经白名单豁免)。

## i18n 配套

- 新增文案必须同时提交 zh-CN 与 en-US;en 语序独立重写,不逐字直译(复数走 `_one/_other`)。
- 带 `count` 参数的键,en 侧会生成复数变体,提交前跑 `pnpm i18n:write` 并补全。
- 中国渠道运营域文案(platform 渠道字段/指引、settings 策略参数名)豁免不译,以 `i18n-exempt` 标记。
