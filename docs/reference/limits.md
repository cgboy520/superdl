# Quotas, rate limits and retention

Every numeric limit the platform imposes on users and operators, layered by "where it can be changed". Values follow the code; this page records where each lives — update it when changing a default. Three-layer configuration chain: per-user override (`user_quota_overrides`) → platform configuration centre (`platform_settings`; policy parameters are its `policy` group, edited online at admin `/policies`) → env default (`SUPERDL_*`, `app/core/config.py`); anything unmarked is a code constant. Effective values are always read through `platform_config.get_runtime_config` (strongly typed `RuntimeConfig`).

Cluster-wide: the SSH NodePort pool is 30000–32767 (excluding 30500), i.e. at most about 2767 instances **with SSH** per cluster (service instances default to `with_ssh=false` and stay out of the pool; `SUPERDL_SSH_PORT_RANGE_START` / `SUPERDL_SSH_PORT_RANGE_END`, exclusion set `SUPERDL_SSH_PORT_EXCLUDED` default `{30500}`; ports taken by other objects are marked blocked and returned by the periodic re-check; level at `GET /api/admin/v1/nodes/port-pool` and metric `superdl_ssh_port_pool_ports{state}`, alerts `SshPortPoolLow` below 10 % free and `SshPortPoolExhausted` below 20 ports). ## Application-layer rate limits

Fixed windows, counters in PG (`rate_limit_counters`), shared across replicas; 429 carries `Retry-After`. The edge layer (Envoy Gateway, `BackendTrafficPolicy` in `deploy/app/k8s/04-gateway.yaml`, `sourceCIDR.type: Distinct`) adds a **per-source-IP** safety net: the `/api/v1` routes of the API domain and the console domain (the real public entry points) 20 rps / 600 rpm each (`superdl-api-ratelimit` / `superdl-console-api-ratelimit`), admin routes 30 rps / 600 rpm (`superdl-admin-ratelimit`, a layer added on top of the source-IP allow-list). The per-IP bucket is keyed by the client IP identified via the `ClientTrafficPolicy` `numTrustedHops` and the ConfigMap `FORWARDED_ALLOW_IPS`; an unregistered upstream hop puts every request into one bucket.

**There is no per-source-IP concurrent connection limit**: `ClientTrafficPolicy.connection.connectionLimit` is the total per Envoy instance, currently 10000. See the rate-limit layering section of [security.md](./security.md).

**Request body hard cap (two layers)**: the edge `BackendTrafficPolicy.requestBuffer` caps the platform API (API domain, console domain `/api/v1`, admin routes) at 1 MiB and anonymous payment callbacks (API domain `/api/v1/webhooks`) at 256 KiB, exceeding → 413; the application layer `RequestBodyLimitMiddleware` (`app/core/body_limit.py`) backs this up at 1 MiB. uvicorn `--limit-concurrency 1024`. `requestHeadersReceivedTimeout: 10s` / `requestReceivedTimeout: 60s` live in `ClientTrafficPolicy superdl-gateway`.
