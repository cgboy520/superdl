# 文案与国际化

语言集 zh-CN(基准)+ en-US,两端全量。文案规范见 `docs/copy-style-guide.md`。

## 契约

后端错误响应体 `{code, message, message_key, params, detail}`;`AppError(code, message=None, *, key=None, params=None, ...)`。
错误体由 exception handler 拼装、不进 openapi schema,`message_key` / `params` 不产生契约 diff。

## 规则与不变量

- 工具链为 react-i18next + i18next + i18next-cli(key 提取 / TS 类型生成 / 硬编码 lint / locale 同步);复数用 i18next 原生 `_one/_other` 后缀,不引 ICU 库。
- 两端各有 `src/i18n.ts`(LanguageDetector:localStorage `superdl.lang` → navigator;fallbackLng zh-CN);`lib/locale.ts` 是 antd ConfigProvider locale、dayjs locale、html lang、document.title 四联动的唯一出口。
- namespace 划分:`web` / `admin` / `shared`(`packages/ui/locales/`,状态表与 format 量词,手维护 + 单测守护)/ `errors`(zh 由后端 MESSAGES 经 `scripts/export_error_messages.py` 生成并 CI no-diff 锁,en 手译)。资源静态 import 全量打包,不做懒加载。
- 后端错误文案以 `core/messages.py` 为单一事实源;前端按 `message_key` 取文案,禁止按 ErrorCode 查表(同一 ErrorCode 对应多条文案)。
- `render_message` 缺键时回落 key 并告警,不得 500;422/500 兜底 `common.validation` / `common.internal`;响应体 `message` 保留中文兜底,测试断 code 不断中文 message。
- 前端经 `packages/ui/src/apiError.ts` 的 `apiErrorText(t, err, fallback)` 查 `errors` ns,缺键回落服务端中文;动态 server key 的 cast 收敛在两端各一的 `useApiErrorText()`,web 的统一错误出口是 `mutations.ts`。
- JSON 是唯一值载体,代码不写 defaultValue;数组文案逐条字面量键,不用 `returnObjects`。
- `packages/ui` 零运行时依赖:状态表只导出 labelKey(内嵌 `shared:` 前缀,`as const satisfies` 保字面量类型),`t` 由调用组件显式持有以订阅语言变更。
- format 函数一律带 locale/t 尾参;en 用缩写单位规避复数,真复数点走 `_one/_other`;金额数字管线纯字符串运算,不过 `Number`。
- en 货币符号用 `CN¥`(裸 `¥` 在英文语境读作日元)。
- `formatDateTime` 两语言统一 `YYYY-MM-DD HH:mm`。
- 约束类文案以后端 message_key 为准,前端禁止 tooltip 与错误弹窗复用同一键。
- 闸门:每 app 一份 `i18next.config.ts`(extract、types 产物入库且 CI 校验无 diff、lint 硬编码与插值 mismatch);每 app `src/locales/locales.test.ts` 锁 zh/en 键集相等、值非空、`{{}}` 占位符逐键一致;`packages/ui` 单测锁状态表 labelKey/hintKey 与 errors 键集 parity;CJK 残留由 web 的 `i18next-cli lint` 与 admin 的 `scripts/check-cjk.sh` 守护,禁词由 `scripts/check-copy-banned.sh` 强制;聚合入口 `pnpm i18n`。
- admin `platform.tsx` 等中国渠道运营域文案不译,CJK 闸门对其豁免。
- e2e 必须钉 `use.locale: "zh-CN"`(CI chromium 默认英文环境会令中文定位器失效);关键路径元素带 `data-testid`。
- 短信不做多语言;站内信存已渲染文案,不随语言切换;legal 页双语待法务出稿,工程预留 per-locale 整页资源位。
