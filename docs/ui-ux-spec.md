# SuperDL UI/UX 规格

两端(`web` 用户控制台 / `admin` 管理控制台)的信息架构、逐屏交互规则与视觉约定。文案规范见 [`copy-style-guide.md`](./copy-style-guide.md),前端契约见 [`reference/web.md`](./reference/web.md) 与 [`reference/admin.md`](./reference/admin.md)。

## 1. 全站交互规则

1. **CTA 即库存**:主页价格墙卡片主按钮直接写「可开实例 N」/「已租完」(禁用态),库存数字在按钮里;市场表格用「可开实例」列 + 售罄行灰置表达同一件事。
   SKU `available_count` 是近似可开实例数(共享档含超卖系数,后端按节点台账估算),**不是物理空闲卡数**;页面一律用「可开实例/台」表述,禁止换算成「卡」。
2. **条件操作一律可见但禁用 + tooltip 说明原因**:操作菜单永不隐藏条目;灰置时 tooltip 写清前置条件(如「关机后才能释放实例」)。
   **占位项的去留有判据**:只有「已排期、按当前设计确定要做」的能力才留 disabled 占位并注「即将上线」,
   没有排期的能力不进 UI。兑现或删除时,[`reference/web.md`](./reference/web.md) 与本节的占位清单同提交更新。
3. **价格公式摊开**:计费项 × 单价 × 数量逐行列出;**「日常费用」单独一栏**(关机也扣的钱:数据盘)。
4. **关机 ≠ 释放,多级删除防护**:关机与释放是两个动作;释放需**键入实例名称** + 勾选「我确认将清除实例盘全部数据(数据盘不受影响)」两道闸才解锁红色按钮。
   `creating` 态的入口文案是「取消创建」,只过键入这道(尚未落盘,清盘确认无意义)。
5. **风险商品知情同意**:下单「共享·经济档」(= 落 hami 池的共享,软切分超卖)弹 modal 逐条列明软件隔离共享、算力为均值保障、性能可能波动、可能被重调度,确认才放行。
   **竞价实例复用同一个 modal 形态**,在**创建页提交前**弹(市场页只是选规格),
   五条 + 一个必勾复选框「☐ 我已知悉竞价实例可能被回收」,勾选前「继续创建」禁用:
   ① 竞价价为按量价的 `{spot_discount_pct}`%,但实例可被平台回收;
   ② 按量或包周期用户需要容量时,平台按创建时间从新到旧回收;
   ③ 回收前提前 `{spot_grace_seconds}` 秒发短信与站内信,请自行保存进度;
   ④ 回收即关机,实例盘保留;已运行时长按实际秒数正常结算;
   ⑤ 有容量时可自行开机;不适合线上服务与不可中断的长任务。
   ②③④ 逐条对应 `apps/api/app/modules/orchestrator/preempt.py` 的三条硬规矩与结算口径,
   **改代码等于改文案,两边同提交**;两个数一律从 `/policies` 读,不硬编码。
6. **给等待路径,不给死胡同**:库存不足给「换个档位」引导;创建失败给「重新创建」按钮与失败原因。

## 3. 用户端

### 3.1 信息架构

```
公开层    /(首页,未登录默认落地页;已登录照常显示,顶栏切「进入控制台」)· /login · /help · /legal/terms · /legal/privacy · /legal/deletion-notice
控制台(全宽顶栏 + 浅色侧栏)
├─ 概览      /dashboard   # 实例数/余额/今日消费/未读通知 + 公告与预警横幅 + 快捷入口
├─ 算力市场  /market      ← 未登录可看,下单跳登录
├─ 容器实例  /instances   ← 登录后默认落地页
├─ 存储      /storage     # 数据盘 + 挂载全景
├─ 费用中心  /billing     # 余额/充值/账单/收支明细/退款/发票
├─ 支持      /support     # 自助排查 FAQ / 联系客服 / 我的工单(/support/:ticketId 为对话流)
└─ 账户设置  /settings    # SSH 公钥 / 通知阈值 / 实名 / 账号(改密·登出·注销)
创建实例     /market/create/:skuId   ← 全页路由,不用弹窗
```

### 3.2 首页与登录

**主页 `/`**:public 顶栏(logo | 算力市场 / 价格 #pricing / 算力排名 #ranking | 登录 / 免费注册);Hero 单帧渐变 + 右侧数据卡
(最低时价 / 可开实例数),不做轮播;快捷入口四宫格全部指向真实能力;**GPU 价格墙**用 `/skus` 公开端点(60s 轮询),卡片与市场页
同构,接口失败整区降级为「前往算力市场」入口、不开天窗;**算力排名**由 `packages/ui/src/gpuSpecs.ts` 静态表驱动(Tabs 半精 FP16 /
单精 FP32 + 横向百分比条,在售型号带跳价格墙的标记,脚注「理论峰值算力」)。页面数字一律取真实数据;三栏页脚(产品/支持/合规)带防挖矿声明,ICP 与公安备案号取自 `/site-config`,缺失则不渲染。

**登录 `/login`**:分屏。左 45% 品牌渐变区(logo / 返回首页 / 口号 / 三条卖点 bullets,lg 以下隐藏),右白底居中三态 Segmented
表单(验证码 / 密码 / 注册,+86 前缀),密码态经「忘记密码」进第四态重置密码。`?redirect=` 按 `new URL(r, origin)` 解析,
只接受同源且 pathname 不以 `//` 开头的目标,并归一化为 `path + search + hash` 再跳。

### 3.3 屏 ① 算力市场

- 页头合规警示条(禁挖矿声明,色走 token)。**「计费方式」chips 六选一,顺序 `按量计费`(默认选中)|`竞价` 低至 4 折 |
  `包日` -5% |`包周` -10% |`包月` -20% |`包年` -30%**,折扣角标一律从 `/policies` 读(周期档取 `100 − period_discount_*`,
  竞价档取 `spot_discount_pct`),不硬编码;+「计费规则」链接(modal)。
  - 选中的规格 `period_enabled=false` 时四个周期项置灰、`spot_enabled=false` 时竞价项置灰,tooltip 分别写
    「该规格暂不支持包周期」/「该规格暂未上竞价档」——措辞须落在「规格不支持」而非「功能未上线」,用户动作是换规格。
  - 选中周期后卡内出现「购买时长」数量选择器(1~36 个周期),并在卡下常驻一行说明:
    **包周期为预付,到期前保有实例;中途释放不退款;未到期的实例即使关机也仍占用库存**。
  - 结算条随之改为周期总价(原价划线 + 折后),明细 popover 摊开「时价 × 份数 × 小时数 → 折扣 → 应付」。
    市场页没有报价接口,这里的数是按 `/policies` 折扣算的**展示值**,明细里必须标明以创建页最终报价为准。
  - **选中竞价时**:结算条价格换成折后时价 + 原价划线 + 「低至 X 折」角标(X 由 `spot_discount_pct` 算);
    卡下常驻一行警示 **竞价实例在容量紧张时会被平台回收,回收前提前 N 秒发短信与站内信**
    (N 取 `spot_grace_seconds`)。竞价**不出「购买时长」数量选择器** —— 它是按量口径的一种价,不是周期。
    知情同意在创建页提交前弹,不在这里弹。
- **「选择规格」卡顶部是 `GPU 算力 / CPU 算力` Segmented**,两栏筛选维度不同,切换即清空已选行:
  - **GPU 栏**筛选链 chips 行:`GPU 型号`(每项后缀 `可开 N`,客户端聚合各 SKU available_count)|`档位`(三档:专用整卡 / 共享·标准 / 共享·经济,后两者由 SKU 所在池派生)
    |`显存` | `GPU 数量`(1/2/4/8,按 `max_gpus_per_instance ≥ n` 过滤;空闲不足 n 的行不过滤掉,改为灰置)。前三行首位为「全部」。
  - **CPU 栏**只有 `vCPU` 与 `内存` 两行 chips(取值域从本栏 SKU 聚合,首位「全部」);档位行、GPU 型号/显存行、GPU 数量行全部不出。
- **SKU 表格(radio 单选)**,列:选择 | 规格名 + 档位徽标(标准档 hint「显存与算力硬隔离」、经济档 hint「性能可能波动」、CPU 档 hint「不带 GPU」,均在 Tooltip)| GPU 型号/显存(标准档写 MIG 切片名,经济档写份额与算力 %;CPU 档表头改「CPU / 内存」、内容写「不带 GPU · N vCPU · MG 内存」)
  | 可开实例(>0 绿数字 / =0「已租完」标签)| 实例配置 vCPU·内存 | 实例盘 | 最高 CUDA(tooltip;CPU 档为「-」)| 价格(钉右列)`¥X.XX/时` 大号 —— **表头随栏分化:GPU 栏「价格(单卡)」,CPU 栏「价格(整机)」**,后者的单价就是整机时价。空闲不足所选卡数的行(CPU 档按 1 台算):radio 禁用 + 行灰置,不隐藏。
- **底部通栏结算条(sticky,与创建页共用 CheckoutBar)**:规格汇总 + `配置费用 ¥X.XX/时`(明细 popover 摊开公式)+ 未登录
  「登录后租用」/ 已登录「下一步:配置实例」(未选中禁用带 tooltip)。
- 未登录可浏览全部内容;30s 轮询;空态「没有符合条件的规格,试试放宽筛选」。

### 3.4 屏 ② 创建实例

全页单栏卡片流,非向导步进。承接市场页选择的查询参数四个:`?gpus=N`(整数 1~8)、`?workload=service`、
`?period=day|week|month|year`、`?market=spot`;**`period` 与 `market=spot` 互斥,同时带则以 `period` 为准**。卡片分区:

1. `计费方式`:同 §3.3 的六个 chips 与数量选择器。选了周期时:
   - 结算条主数字换成「包月费用 ¥X / 月」(原价划线 + 折后),**不显示「日常费用 约¥x/日」那一行**(它是按量口径),
     换成「到期时间 约 YYYY-MM-DD」;数据盘的日常费用照旧单列(数据盘不在包周期覆盖范围内,关机也扣)。
   - 主按钮文案换成**「支付并创建」**(一次性预扣,与按量的「创建并开机」不是同一个动作),提交 `market/period/period_count`。
     余额不足时按钮变「余额不足,去充值」,文案指向充值而不是按量那句「余额不足以支撑 1 小时」。

   **选了竞价时**:结算条主数字是折后时价(原价划线 + 折扣角标),「日常费用」那一行照旧(竞价与按量同口径,
   照常出小时账);主按钮点下去**先弹竞价知情同意 modal**(§1 规则 5),勾选并确认才真正提交,
   提交体 `market='spot'`、不带 `period`。**部署服务形态(`?workload=service`)选竞价时卡内多一条警示**:
   「竞价实例可被回收,不建议用于对外服务」——**只警示,不禁止**。
2. `已选规格`:SKU 单行表格回显(市场同列去掉「空闲 GPU」)+ `GPU 数量` chip(1/2/4/8,受 SKU 上限)+「更换规格」链接。
   CPU 规格不出 `GPU 数量` chip,提交 `gpu_count: 0`(后端契约:`max_gpus_per_instance=0` 的规格只收 0)。
3. `镜像`:两枚 Tab —— **平台镜像**(级联:框架 → 框架版本 → Python → CUDA,标注「已在节点预热,秒级启动」)/ **自定义镜像**
   (只有仓库地址一栏,注明镜像须内置 SSH 22 与 JupyterLab 8888、私有仓库凭据联系客服配置)。
4. `数据盘(可选)`:「不需要 / 新建 / 挂载已有盘」;「新建」为行内直建(名称 + 容量滑块,单价来自 `/policies` 折日展示;先建盘
   再建实例,建盘成功而建实例失败须提示「数据盘已创建并开始计费,可在存储页管理」);说明:独立于实例、关机与释放均保留、**关机也计费**。
5. `SSH 密钥`:选择已有公钥(多选);无密钥时行内添加小表单(不支持密码登录)。
6. `实例名称`(可选,默认生成)。

**服务形态**(`?workload=service`,入口在市场页「部署服务」):同一条卡片流,把上面第 3~6 张卡换成:

3. `容器`:镜像地址(**后端硬闸**:服务容器 `restartPolicy=Always`,必须钉死版本,`:latest` 与不写 tag 一律拒,
   前端同步拦一道以求早报错;**这张卡没有平台镜像 Tab**)/ `启动命令`(留空则用镜像 ENTRYPOINT)/ `启动参数`(可增删的行列表)/
   `环境变量`(变量名 + 值 + `密文` 勾选 + 删除的表格;勾了密文后值不再回显,只能整条覆盖)。
   与开发机形态的差别要写在卡片说明里:**服务型容器不要求内置 SSH 与 JupyterLab**。
4. `对外服务`:`服务端口`(必填,不得为 22 / 8888)/ `协议`(HTTP,TCP 与 gRPC 为 disabled 选项)/ `健康检查`(路径,
   注明「返回 2xx 才判就绪并进流量;留空则容器启动即就绪」)/ `访问地址`(灰字「创建后生成」)/
   `访问鉴权`(单选:需要 API Key / 公开访问,后者副文案明确「任何人可调用」;
   注明「平台在网关校验 `Authorization: Bearer`,你的容器无需实现鉴权」)。
5. `数据盘(可选)`:同上。
6. `实例名称` + `☐ 同时开放 SSH(便于调试,会占用一个 SSH 端口)`,默认不勾。
   勾上后在其下方内联出 SSH 公钥选择块(后端对 `with_ssh=true` 要求 `ssh_key_ids` 非空);取消勾选时提交空数组。

主按钮文案「部署服务」(选了周期时同样换成「支付并创建」)。⚠ 禁词闸拦「一键」(白名单只有 `一键(加入|添加)`),**不能写「一键部署」**。

底部 CheckoutBar 在 §3.3 基础上加「日常费用 ¥X/日」栏(注释:关机也会产生,数据盘),明细 popover 逐行摊开(单价 × 卡数,
CPU 规格写「整机 ¥X.XX」不乘卡数;盘价 GB·月折日;注明计费依据为实例事件流水);余额不足时按钮变「余额不足,去充值」;
按量主按钮「创建并开机」,经济档与竞价档先弹各自的知情同意 modal(两档同时命中时逐个弹,顺序不敏感),创建带 Idempotency-Key。

### 3.5 屏 ③ 容器实例列表

- 页头:标题 + 常驻策略提示条(「停止的实例欠费冻结 72 小时后将回收实例盘,数据盘不受影响」)+ 工具行
  (`租用新实例` 主按钮 / 刷新 / `密钥登录设置`(→ /settings#ssh)/ 搜索框,客户端过滤 name/uuid)。
- **到期横幅**(名下有 `subscription.status='active'` 且剩余天数 ≤ `policies.period_expire_warn_days` 的实例时出现):
  写清哪台、什么时候到期、到期后自动停机、72 小时内未续费将回收实例盘(数据盘不受影响),带 `立即续费` 与
  `开启自动续费` 两个按钮。判据全部来自列表已有的 `subscription` 内联字段与 `/policies`,不为横幅单开接口。
- 表格 6 列:①`名称 / ID`(可改名)+「详情」链接(双击行同效);②`状态` 徽标(冻结态附红色回收倒计时,hover 出
  回收策略 tooltip);③`规格详情` GPU 型号 × 数量 + 档位徽标,popover 展开完整配置;④`GPU 利用率` 迷你 sparkline(近 1h,running 时;`GET /api/v1/metrics/instances` 批量端点,
  45s 独立轮询)+ 末值 %,断源时灰字「监控暂不可用」而页面其余正常;⑤`计费` 随购买模式分化:按量为 `按量` 标签 + `¥X.XX/时 × N 卡` + 第二行 `今日 ¥Y.YY`
  (`/bills/daily-summary`,60s 轮询);包周期为 `包月 · 剩 23 天` 标签 + 第二行 `¥X/月`,剩余天数由
  `subscription.expires_at` 算(格式化函数在 `packages/ui`,不在页面里各写一份 dayjs 逻辑),
  临期变警示色、已到期写「已到期」。包周期实例**不显示今日消费**(不产生小时账,该行恒 ¥0.00);
  **竞价为 `竞价` 标签(`marketMap.spot`)+ `¥X.XX/时` + 一枚「可回收」标记(`spotReclaimTag`)**,
  第二行的今日消费**照出**(竞价与按量同口径出小时账);⑥`操作` `开机` `关机` `更多 ▾`,全部条目常显,灰置用 tooltip 写明原因。
- 行展开区(仅 running / failed 可展开,不占列):running 展开快捷工具 —— `SSH` 一键复制指令 + `JupyterLab`
  直达 + `实例监控`;failed 展开失败原因,未运行过的再给绿色 `未扣费` 标签与 `重新创建` 按钮,运行过的注
  「按实际运行结算」。access 与 events 只在展开时才拉、不在行内预取,列表页因此不按行数放大接口调用。
- 「更多 ▾」的条目与顺序:`重启` / `事件记录` /(包周期)`续费`·`自动续费` /(竞价)`转按量` /(按量)`转包周期` /
  `无卡模式开机`(disabled 占位,注「即将上线」)/ `释放实例`(红;`creating` 态文案换成「取消创建」)。
  **`转包周期`** 只对 running / stopped 的按量实例可用,其余灰置并在 tooltip 写明原因。
  它**不是设置项,是一次性预扣的支付动作**:点开的 modal 与续费同形(周期 chip + 数量 + 费用明细 +
  余额变化 + 新到期时间),确认即扣款,且必须写清**转换前那段按量费用会先结清**、转换后
  **中途释放不退款**、周期从**现在**起算。转换失败要给可执行说明:结算追平中(稍后再试)与
  该规格不支持包周期(换规格)是两件事,不能都报「操作失败」。
  **`转按量`** 只对竞价实例可用;确认弹窗必写的两条(转换后不再被回收、当前整点小时整体改按按量价结算)
  与「不带 `Idempotency-Key`、已是按量原样返回 200」的口径见 [reference/web.md](./reference/web.md)。
  不放:更换镜像 / 重置系统 / 升降配置 / 修改 SSH 密码(密钥制)/ 扩缩数据盘(归存储页)/ 保存镜像(无排期,按规则 2 不进 UI)。
- 不做的列:地区 / 主机号、本地磁盘 %、镜像状态、付费方式独立列、释放时间独立列(倒计时在②)。
- 关机二次确认:说明按量实例关机后 GPU 释放、再开机可能库存不足;**包周期实例的关机确认要说清另一件事**——
  周期内关机不退费,但平台替他留着这台的库存,回来能开得起来。释放走规则 4 的多级防护,
  且包周期实例的释放确认必须额外写明**预付不退款、剩余天数作废**。
- **续费 modal**(列表与详情共用):自上而下五块 —— `当前周期`(起止时刻)/ `续费时长`(四个周期 chip + 数量,
  可与当前周期不同)/ `费用明细`(实例费用、周期折扣、应付三行)/ `可用余额`(当前 → 扣后)/ `新到期时间`。
  确认前的明细是按 `/policies` 折扣算的**预览值**,确认后以响应里的 `quote` 为准并在成功提示里给出实扣金额;
  每次打开 modal 生成一个 `Idempotency-Key`,重放不重复扣款。**提前续费从老到期时刻起算**,modal 里要写出来。

### 3.6 屏 ④ 实例详情

头部:名称 / 状态徽标 / 档位 + 操作组(同列表)+ 关键信息条(ID / 规格 / 单价 / 今日消费 / 创建时间);
包周期实例的标签行多一枚 `包月 · 剩 23 天`、关键信息条的「今日消费」换成「到期时间」,订阅已到期时开机按钮禁用 +
tooltip「包周期已到期,请先续费」(后端同判据:到期开机报 409);竞价实例的标签行多一枚 `竞价` 标记(`marketMap.spot`)。
页尾危险区:释放实例(红,多级防护)。

Tab 集合与顺序固定为 `监控 / 服务 / 连接 / 日志 / 事件 / 账单`(白名单常量 `DETAIL_TABS`,`?tab=` 直达):

- **监控**(默认):四张 ECharts 曲线卡 —— GPU 利用率 / 显存占用 / CPU / 内存;1h/6h/24h;非 running 提示暂无实时监控,
  断源(503)显示「监控数据暂不可用,不影响计费」。
- **服务**(仅 `workload_type='service'` 渲染):
  - `服务端点`卡:完整 URL + 复制;副行「容器端口 X · 健康检查 Y · 就绪 ✓/✗ · 需要 API Key / 公开访问」。
    **就绪为 ✗ 时不报故障**,如实显示并提示「检查容器日志与健康检查路径」(平台不替用户杀实例,见
    [reference/services.md](./reference/services.md))。
  - `API Key`表:名称 / Key(前缀 + 省略号)/ 最近使用 / 创建时间 / 吊销;右上「新建 Key」。
    表尾常驻灰字「Key 完整值只在创建时显示一次,遗失只能吊销后新建」;**新建 Key modal 的成功态**复用管理端
    TOTP 恢复码那套一次性展示(大号等宽全值 + 复制按钮 + 「关闭后无法再查看」红字),**关闭前必须勾选「我已保存」**。
  - `调用示例`卡:可复制的 curl,Key 位置用前缀 + 省略号占位;URL 用端点根,不拼 `health_path`(那是探针路径)。
  - `容器配置`只读回显:镜像、启动命令、启动参数、容器端口/协议/健康检查/访问鉴权/SSH,
    以及环境变量 —— **明文项显示值,密文项只显示键名**(接口只回 `env_secret_keys`)。
    这些配置创建时写入、之后不可改,卡片里要说清楚。
  - `require_api_key=false`(公开访问)时 Key 表仍然渲染,附一条说明「当前端点公开访问,网关不校验 Key」。
- **连接**:SSH 卡片(完整登录指令 + 复制 + 仅密钥登录说明)+ JupyterLab 卡片(打开按钮 + token 重置)。
  服务形态下 SSH 卡片按 `with_ssh` 决定是否渲染,Jupyter 卡片一律不渲染(服务型实例不建 Jupyter 入口)。
- **日志**:容器日志末 N 行 + 行数选择 + 自动刷新(10s)开关 + 下载 `.log`;截断时注明「仅显示末尾 N 行」;
  非 running/stopping 时提示「实例运行中或关机中才能读取容器日志」。
- **事件**:状态迁移时间线(时间 / 事件 / 操作者 / 计费影响),明示「此记录即计费依据」;
  reason 文案映射必须覆盖 `preempted`(竞价被回收)—— 它走 `stopping → stopped`,状态上与用户自己关机无异,
  reason 是唯一区分点。
- **账单**:该实例小时账单表。

### 3.7 屏 ⑤ 费用中心

### 3.8 屏 ⑥ 存储

- **运营总览**:KPI 行(今日收入含昨日对照 / 本月收入 / 今日新注册带环比箭头 / 活跃实例 / 付费租户 / 告警数);主图表「实际
  超卖率 vs 真实利用率」按池并置(柱 = 实际超卖率,折线 = 24h 平均利用率,60%/85% 阈值辅助线);GPU 池占用堆叠条(按节点池

  为 0、实际超卖已达设定上限时标红;编辑抽屉全参数表单(含 `包周期` 与 `竞价档` 两个 Switch,后者**新建时默认关**,说明写
  「开启后该规格可按竞价价售卖;竞价实例在容量紧张时会被平台回收」)+ 超卖风险提示(「变更仅影响新实例;显存超卖 >1.2 需二次确认」)+ 编辑
  必填原因,右侧实时容量预览(匹配节点 / 可用 GPU / 总 GPU / 预估实例数 + 警告);新建可「从集群资源创建」带出推荐参数。

  + 点行开账单下钻侧滑(余额与累计消费摘要 + `小时账单`/`资金流水` 两 Tab,与用户端同源);全局实例表按状态/实例名/节点名
  过滤(实例名/归属/节点/状态/规格/购买模式/SSH 端口/创建时间),操作 `强制停止` 与 `强制回收` 两个入口不合并 ——
